## Pattern

**Hero + Testimonials + CTA**

- Conversion: Social proof before CTA. 3–5 testimonials with photo + name + role.
- CTA after social proof.
- Sections: Hero → Problem Statement → Solution Overview → Testimonials Carousel → CTA

## Typography

### Headings: Barlow Condensed
- Weights: 400, 500, 600, 700
- Mood: Sports, fitness, athletic, energetic, condensed, action
- Usage: Headlines, section titles, large display text

### Body: Barlow
- Weights: 300, 400, 500, 600, 700
- Mood: Clean, readable, versatile
- Usage: Body copy, labels, descriptions


## Anti-Patterns (Avoid)

- ❌ Excessive decoration / visual clutter
- ❌ Pure white backgrounds (use subtle off-white)
- ❌ Emoji as icons (use Lucide icons — already in deps)
- ❌ Flat design without depth
- ❌ Gray-on-gray text combinations

---

## Pre-Delivery Checklist

- [ ] No emojis as icons (use SVG: Lucide icons)
- [ ] `cursor-pointer` on all clickable elements
- [ ] Hover states with smooth transitions (150–300ms)
- [ ] Light mode: text contrast 4.5:1 minimum
- [ ] Focus states visible for keyboard nav
- [ ] `prefers-reduced-motion` respected
- [ ] Responsive: 375px, 768px, 1024px, 1440px
